# 세션 인수인계

AI 작업 세션이 이어받을 상태를 적는다. 새 세션은 이 파일을 먼저 읽고, 작업을 마치면 갱신한다. `.claude/settings.json`의 훅이 시작할 때 이 파일을 보여 주고, 작업 트리에 이 파일보다 나중에 바뀐 파일이 있으면 종료를 막는다.
여러 세션이 동시에 쓰므로 바꿀 부분만 Edit로 고치고 파일 전체를 다시 쓰지 않는다. 다른 세션이 쓴 항목은 건드리지 않는다([AGENTS.md](../AGENTS.md)).

마지막 갱신: 2026-10-20 (웹 다크 모드, osiv E2E와 규칙 생성기 보강, 추천 규칙 자동 OFF)

## 작업 규칙 (사용자 지시)

- 항상 한국어. 보고는 [AGENTS.md](../AGENTS.md) 형식("완료" / "결정 필요")으로 짧게.
- 커밋·푸시는 사용자가 하라고 할 때만 한다. 이력 재작성 금지.
- 웹은 디자인이 중요해 백엔드를 먼저 한다. 서버는 로컬(+터널/모바일)에서 쓴다.
- 어느 PC에서 써도 같은 기능을 제공해야 한다. PC 전용 설정(`settings.local.json`, `~/.claude` 메모리)에 기능을 두지 않는다.
- 비밀번호·토큰·키는 이 파일에 적지 않는다.

## 로컬 실행 환경

PC마다 따로 준비한다. 이 PC의 상태는 저장소에 없으므로 다른 PC에서는 아래 순서로 다시 만든다. 새 PC 설치 순서(클론·`docker compose up -d`·`scripts/dev-up.sh`·`installDist`·`~/.claude/settings.json`의 `ILSIM_RUNNER_BIN`·`jev-key set`·플러그인 설치·프로젝트 등록·규칙 승인)는 README "새 PC에서 설치하기"에 정리했다(2026-10-25). 2026-10-27 사용자 지시로 복붙만 하면 되게 다시 정리했다(`~/ilsim` 기준, PATH·`ILSIM_RUNNER_BIN` 자동 등록, 플러그인 `enable`, JEV 키는 따로 붙여 넣기).

- 서버: `./gradlew :ilsim-server:bootRun`. MySQL(도커 `ilsim-mysql`, DB/계정/비밀번호 기본값 `ilsim`, 호스트 포트 기본 3333 — 2026-10-25 다른 PC에서 3306~3309가 쓰여 사용자 결정으로 3306에서 변경, 이 PC는 컨테이너를 다시 만들어 데이터 유지 확인)이 필요하다. 처음 띄우면 `~/.ilsim/token`, `~/.ilsim/server-secret.key`가 생긴다.
- JEV 키: `ilsim-runner jev-key set`(표준 입력)으로 등록하면 DB에 암호화 저장되고, 일심 MCP 서버가 시작할 때 서버에서 받는다. 환경 변수는 필요 없다. 서버 비밀 키(`server-secret.key`)가 PC마다 다르므로 DB를 옮기면 키를 다시 등록한다.
- Runner: `./gradlew :ilsim-runner:installDist`. `run` 명령은 없어졌다(2026-10-24). 프로젝트는 `ilsim-runner add <id> <경로>`, `set <id> test "<명령>"`으로 등록한다(`~/.ilsim/runner.json`). Claude 앱은 `ilsim-plugin`(MCP·훅)을 설치해 쓰고(`claude plugin marketplace add dochiri0916/ilsim` → `claude plugin install ilsim@ilsim`, 이 PC는 2026-10-24 설치), 플러그인은 `ILSIM_RUNNER_BIN` 또는 PATH의 `ilsim-runner`를 실행한다. 데스크톱 앱은 셸 PATH를 받지 않아 사용자 설정 `~/.claude/settings.json`의 `env.ILSIM_RUNNER_BIN`에 실행 파일 경로를 넣어야 MCP가 연결된다(이 PC는 넣어 둠). 일심 저장소 자체도 Runner에 `ilsim`으로 등록돼 있어 플러그인 훅이 이 저장소의 편집을 막으므로, 저장소 `.claude/settings.json`에 `enabledPlugins."ilsim@ilsim": false`를 두어 일심 개발 세션에서는 플러그인을 끈다(`claude plugin disable ilsim@ilsim --scope project`로 넣음, 이미 열린 세션에는 반영되지 않아 새 세션부터 적용). 알려진 빈틈: Bash에서 스크립트로 파일을 쓰는 일부 경우는 PreToolUse 패턴 검사가 못 잡는다(커밋은 Git pre-commit 훅이 막는다). CLI 확인용: `claude -p --plugin-dir ilsim-plugin --permission-mode acceptEdits --allowedTools "mcp__plugin_ilsim_ilsim__*" "Bash(./gradlew:*)" "<요청>"`(sandbox 폴더에서).
