# Outbox / Inbox 컨벤션

아래 규칙은 필수 컨벤션이며, 현재 구현의 완료 상태가 아닌 적용 기준이다.

- 전달은 at-least-once를 전제로 한다. 업무 변경과 Outbox 저장은 같은 트랜잭션에서 수행하며, 브로커를 업무 트랜잭션 안에서 직접 호출하지 않는다.
- `eventId`는 Outbox 저장 전에 UUID v7으로 한 번 생성하고, 재시도·재발행·DLQ 재처리에서도 유지한다. `sequence`는 최초 저장 시 부여해 최초 전송 전에 확정하고, Outbox를 다른 행으로 재저장하더라도 최초 값을 유지한다. 발급 범위와 조회 모델의 비교 규칙은 [BC 이벤트](bounded-context-events.md) 컨벤션을 따른다. Outbox의 `event_id`에는 UNIQUE 제약을 두며 업무 키를 멱등성 키로 사용하지 않는다.
- Inbox의 멱등성 키는 `(event_id, consumer)` 복합 UNIQUE 제약이다. `consumer`는 BC·핸들러별 안정적인 식별자로 둔다.
- Inbox 처리 완료 기록·업무 변경·후속 Outbox 저장은 함께 커밋하고, 실패하면 함께 롤백한다. 외부 부수 효과는 후속 Outbox로 전달하며, DB 커밋 이후에만 ACK 또는 offset을 커밋한다.
- Inbox는 처리 대기·완료·실패를 구분한다. 지정한 멱등성 제약의 충돌만 중복 후보로 판단하고, 처리 완료일 때만 업무를 생략한다. 실패한 트랜잭션에서는 처리를 계속하지 않으며 동시 수신이 업무를 중복 실행하지 않도록 한다.
- Outbox 발행 완료는 브로커 인수 확인 완료를 뜻하며, 소비자의 업무 처리 완료와 구분한다. 확인 전에는 완료로 기록하지 않으며, 장애로 재발행되어도 Inbox로 중복 제거한다.
- 기본 발행 방식은 폴링 + Waker이다. AFTER_COMMIT에서는 Waker 신호만 보내며, 신호가 유실되어도 폴링으로 복구한다.
- 다중 인스턴스 폴러는 `FOR UPDATE SKIP LOCKED`로 재시도 시각이 도래한 미완료 메시지를 조회한다. 브로커 인수 확인과 상태 갱신까지 발행용 트랜잭션에서 처리하고, 전송 대기 시간과 처리량을 제한한다.
- 파티션 키만으로 업무 이벤트 순서를 보장하지 않는다. 엄격한 순서가 필요한 업무는 aggregate별 발행·소비·재처리를 직렬화하고 선행 실패 해결 전 후속 처리를 막는다. 조회 모델의 오래된 이벤트 판정은 BC 이벤트 컨벤션을 따른다.
- 일시적 오류만 횟수 제한과 지수 백오프·jitter를 적용해 재시도한다. 실패 횟수와 다음 시도 시각은 업무 롤백·프로세스 재시작에도 유지하며, 복구 불가능한 오류나 한도 초과 메시지는 DLQ에 보존한다.
- 실패 상태와 DLQ 전달은 장애 후 복구할 수 있어야 한다. DLT 인수 확인 전에는 원본 offset을 커밋하지 않으며, 실패 상태의 재수신을 처리 완료로 간주하지 않는다. 원본 메시지와 실패 원인을 보존하고 개인정보는 오류 기록에서 제거한다.
- DLQ 재처리는 대상 소비자와 원인을 확인한 뒤 실패 상태를 처리 대기로 전환하고 재시도 정보를 초기화한다. 이미 완료한 소비자의 기록은 유지하며, 재전달 예약과 재처리 이력을 보존한다.
- 주기·배치 크기·전송 timeout·재시도 한도·보관 기간은 설정으로 관리한다. 완료된 Outbox만 보관 기간 이후 정리한다. 정리는 배치 단위로 수행하며 미완료 전달이나 진행 중인 재처리에 필요한 자료는 삭제하지 않는다.
- Inbox는 원본 토픽·DLT·offset 초기화·수동 재생을 포함한 최대 재전달 기간보다 오래 보관한다. 보관 기간 밖의 재생은 중복 방지 정책을 먼저 마련한다.
- 폴링과 CDC는 BC 단위로 하나만 사용한다. CDC 전환 시 기존 이벤트 계약과 Inbox 멱등성을 유지하며, Outbox 삭제는 전달 진척·변경 로그 보존·복구 범위를 확인한 뒤 수행한다.

모델·패키지 배치는 [도메인](domain-conventions.md)·[어댑터](adapter-conventions.md), PK와 저장 규칙은 [영속성](persistence-conventions.md), 메시지 계약과 순서 메타데이터는 [BC 이벤트](bounded-context-events.md) 컨벤션을 따른다.
