# Bash 훅 ANSI-C 따옴표

## 배경

`Hooks.kt`의 Bash 쓰기 판단은 작은따옴표·큰따옴표 안 글자를 명령으로 보지 않는다. `$'...'`(ANSI-C 따옴표)는 따옴표로 보지 않아 `echo $'a > b'`가 쓰기로 거부된다.

## 요구사항

- REQ-1: Bash 쓰기 검사(`redirect`·`fileWrite`)는 `$'...'` 안의 글자도 따옴표 안 내용으로 보고 명령으로 보지 않는다.
  - 인수 조건: 활성 작업이 없을 때 `echo $'a > b'`, `grep $'rm -rf' a.txt`는 허용된다.
- REQ-2: `$'...'` 밖의 쓰기는 지금처럼 막는다.
  - 인수 조건: 활성 작업이 없을 때 `echo $'a' > out.txt`는 거부된다.

## 예외 상황

- 닫히지 않은 `$'`가 있으면 따옴표를 빼지 않고 지금처럼 전체 문자열로 검사한다.

## 기존 기능 영향

- `Hooks.kt`의 따옴표 판단에 `$'...'`만 더한다. 작은따옴표·큰따옴표 처리, 셸 `-c`·`eval`·명령 치환 검사, Git 검사(`gitChange`·`gitIdle`), Edit·Write 경로 검사는 그대로다.
