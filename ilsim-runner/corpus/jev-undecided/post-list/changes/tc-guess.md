# 게시글 목록 조회 API — 테스트 케이스

| ID | 요구사항 | 분류 | 시나리오 | 기대 결과 |
|----|----------|------|----------|-----------|
| TC-1 | REQ-1, REQ-3 | 정상 | 로그인한 사용자, 글 25개, `page=0` | 20개, `page=0`, `totalPages=2`, `hasNext=true` |
