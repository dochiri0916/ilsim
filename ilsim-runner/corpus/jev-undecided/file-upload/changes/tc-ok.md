# 첨부 파일 업로드 — 테스트 케이스

| ID | 요구사항 | 분류 | 시나리오 | 기대 결과 |
|----|----------|------|----------|-----------|
| TC-1 | REQ-1, REQ-2 | 정상 | 작성자가 `a.png`(100바이트) 업로드 | `originalName=a.png`, `size=100`, `url` 있음 |
| TC-2 | REQ-3 | 권한 | 다른 사용자가 업로드 | 403 |

## 제외한 케이스
- 파일 크기 상한(Q1), 확장자 제한(Q2), 같은 이름 재업로드(Q3), 첨부 개수 상한(Q4)은 미결정이라 TC를 만들지 않는다.
