# 기여 규칙

## 컴포넌트

- 컴포넌트는 함수 컴포넌트로만 만든다. 클래스 컴포넌트를 쓰지 않는다.
- 파일 하나에 컴포넌트 하나를 두고 이름 있는 export(`export function`)를 쓴다. `export default`는 쓰지 않는다.
- 스타일은 같은 폴더의 CSS Module(`*.module.css`)로 한다. 인라인 `style` 속성을 쓰지 않는다.

## API 호출

- 서버 호출은 `src/api/client.ts`의 `apiClient`로만 한다. 컴포넌트·훅에서 `fetch`나 `axios`를 직접 부르지 않는다.
- 응답 타입은 `src/api/types.ts`에 정의한다.

## 커밋

- 커밋 메시지는 Conventional Commits(`feat:`, `fix:` 등)로 쓴다.
