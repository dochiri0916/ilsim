# 테스트 명세: 빌드·검증 문서에 corpus check 안내 추가

대상은 문서 한 파일(`docs/repository.md`)의 변경이다. 런타임 동작이 없으므로 모든 TC는 `git diff`, `grep`, 육안 검토, 문서에 적힌 명령의 실제 실행으로 확인한다.
미결정 사항 1~4(명령 형태, 블록 안팎, 옵션 표기, `installDist` 언급)는 결정 결과에 따라 해당 TC의 분기를 적용한다.

## 제외한 분류

- 상태 전이: 문서 한 줄 추가이며 상태를 가진 대상이 없다.
- 동시성: 동시 실행되는 코드 경로가 없다(문서 편집만 있음).
- 멱등성: 같은 변경을 두 번 적용하는 시나리오가 요구사항에 없다. 다만 중복 줄 방지는 TC-1(추가 정확히 1줄)이 커버한다.
- 트랜잭션/롤백: 저장소나 데이터 변경이 없다.
- 인증·인가: 권한이 개입하는 기능이 없다.
