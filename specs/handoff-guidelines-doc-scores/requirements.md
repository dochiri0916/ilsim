# 인수인계에 지침 점수 작업 기록

## 배경

일심 작업 bb013d57(`guidelines-final-doc-scores`)은 `ilsim-runner guidelines` CLI의 문서 줄을 참조 반영 뒤 최종 결과로 바꿨다. 이 작업은 일심 단계로만 진행돼 `docs/handoff.md`에 결과가 남지 않았다. [AGENTS.md](../../AGENTS.md)는 세션 작업을 마치면 인수인계를 갱신하되, 여러 세션이 동시에 쓰므로 바꿀 부분만 Edit로 고치고 다른 세션 항목은 건드리지 않게 한다.

## 요구사항

- REQ-1: `docs/handoff.md`에 bb013d57 작업 결과 항목을 하나 추가한다.
  - 인수 조건: 항목 제목에 날짜(2026-10-25), 작업 ID(bb013d57), 브랜치(`ilsim/guidelines-final-doc-scores-bb013d57`)와 main 미병합 상태가 있다.
  - 인수 조건: 바뀐 동작이 적혀 있다. 문서별 최종 관련도(구간 최고값)·선택 구간 수 출력, 관련도 내림차순·경로 오름차순, 거름 점수 0.2 이하였다가 참조로 선택된 문서의 "참조" 표시, 문서 거름 중복 JEV 호출 제거.
  - 인수 조건: 사용자 결정(거름 점수 자체는 출력하지 않음)이 적혀 있다.
  - 인수 조건: 추가한 공개 함수(`Guidelines.selection`·`documentScores`·`documentLine`)와 `select`가 그대로라는 점이 적혀 있다.
  - 인수 조건: 검증 결과가 적혀 있다. 4단계 통과(구현 단계 tests PASSED, requirements UNCERTAIN), `:ilsim-runner:test` 통과, 실제 JEV로 CLI를 실행하지 않음.
- REQ-2: 항목은 날짜 순 작업 기록 섹션의 맨 뒤(2026-10-24 JEV 위험 선별 섹션 다음, `## 사용자 확인 대기` 앞)에 `##` 섹션으로 넣는다.
  - 인수 조건: 기존 섹션 순서가 유지되고 새 섹션이 그 위치에 하나만 있다.
- REQ-3: 기존 내용은 바꾸지 않는다.
  - 인수 조건: `git diff`에서 `docs/handoff.md`의 변경은 새 섹션 추가뿐이고 삭제·수정된 줄이 없다.
  - 인수 조건: 비밀번호·토큰·키나 PC별 절대 경로를 적지 않는다.

## 예외 상황

- 다른 세션이 그사이 인수인계를 고쳤으면 갱신 직전에 다시 읽고 그 내용을 지우지 않는다.
- `## 사용자 확인 대기` 제목이 없으면 마지막 날짜 섹션 바로 뒤에 넣는다.

## 기존 기능 영향

- 문서만 바뀐다. 코드·테스트·빌드에는 영향이 없다.
- 상단 "마지막 갱신" 줄은 다른 세션 기록이므로 바꾸지 않는다(미결정 사항 1).
