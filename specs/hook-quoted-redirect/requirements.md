# 훅 따옴표 안 리디렉션 오탐

## 배경

`Hooks.preToolUse`는 Bash 명령 문자열 전체에 `redirect`·`fileWrite` 정규식을 적용한다. 그래서 따옴표 안 글자인 `>`도 출력 리디렉션으로 본다. 2026-10-25 E2E에서 일심 작업이 끝난 뒤 `git merge --no-ff <브랜치> -m "...Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>"`가 "이 저장소는 일심 관리 대상입니다. 파일을 고치기 전에 … start_task로 작업을 시작하세요"로 거부됐다. 메시지를 파일로 넘기는 `-F`로 우회해야 했다. 설계 문서([mcp-design.md](../../docs/mcp-design.md) 5. 강제(훅))는 작업이 끝난 뒤의 병합·푸시를 허용한다.

## 요구사항

- REQ-1: Bash 쓰기 검사(`redirect`·`fileWrite`)는 셸이 글자 그대로 넘기는 따옴표 안 내용을 명령으로 보지 않는다.
  - 인수 조건: 활성 작업이 없을 때 `git merge --no-ff b -m "x <a@b.c>"`는 허용된다(거부 메시지 없음).
  - 인수 조건: 활성 작업이 없을 때 `git log --format='%h > %s'`, `echo "a > b"`처럼 `>`가 작은따옴표·큰따옴표 안에만 있는 명령은 허용된다.
  - 인수 조건: 따옴표 안에만 있는 `rm `·`mv `·`sed -i` 같은 글자(예: `grep "rm -rf" a.txt`)도 쓰기로 보지 않는다.
  - 인수 조건: 큰따옴표 안의 `\"`는 따옴표를 닫지 않는다(`echo "a \" > b"`는 허용).
- REQ-2: 따옴표 밖의 쓰기는 지금처럼 막는다.
  - 인수 조건: 활성 작업이 없을 때 `echo "a" > out.txt`, `echo 'x' >> src/a.kt`, `rm "a.txt"`는 거부된다.
  - 인수 조건: 저장소 밖 절대 경로로의 리디렉션(`> /tmp/x`, `> "/tmp/x"`)과 `/dev/null`·`>&`는 지금처럼 허용된다.
  - 인수 조건: 따옴표가 닫히지 않은 명령은 따옴표를 빼지 않고 지금처럼 전체 문자열로 검사한다.
- REQ-3: 따옴표 안 내용이 실행되는 경우는 계속 쓰기로 검사한다.
  - 인수 조건: `bash -c "echo x > a"`, `sh -c 'rm a'`, `zsh -c ...`, `eval "..."`처럼 셸에 문자열을 실행시키는 명령은 따옴표 안까지 검사해 거부된다.
  - 인수 조건: 큰따옴표 안의 명령 치환(`"$(echo x > a)"`, 백틱)은 검사해 거부된다.
- REQ-4: Git 검사(`gitChange`·`gitIdle`)와 Edit·Write 도구 검사는 바뀌지 않는다.
  - 인수 조건: `git commit -m "x"`는 활성 작업 유무와 관계없이 거부되고, 활성 작업 중 `git merge`는 거부된다(지금과 같다).

## 예외 상황

- 빈 따옴표(`""`, `''`)와 이어 붙은 따옴표(`"a"'b'`)는 각각 따옴표 쌍으로 처리한다.
- 작은따옴표 안의 `\`는 이스케이프가 아니다(`'a\'`는 `'a\'`에서 닫힌다).
- 따옴표 밖의 `\>`(이스케이프된 `>`)는 이번 범위가 아니며 지금처럼 쓰기로 본다.
- here-document 본문(`<<EOF` … `EOF`)의 `>`는 이번 범위가 아니다(미결정 사항 1).

## 기존 기능 영향

- `Hooks.kt`의 Bash 쓰기 판단만 바뀐다. 거부 메시지, Edit·Write 경로 검사, Git 검사, Stop·UserPromptSubmit 훅, Git pre-commit 훅은 그대로다.
- 따옴표 안 글자 때문에 거부되던 명령(커밋·병합 메시지, `grep`·`git log --format` 패턴, `echo`/`printf` 출력)이 허용된다. 따옴표 밖 쓰기는 지금처럼 막히므로 강제 범위는 줄지 않는다.
- 설계 문서 5. 강제(훅) 표의 Bash 차단 조건에 "따옴표 안 글자는 검사하지 않음(셸 `-c`·`eval`·명령 치환은 검사)"을 덧붙인다.

## 미결정 사항
